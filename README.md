# c23

This is a collection of utilities and data structures
written as an excercise in exploring the latest features
of C '23.

Current features:
- Arena allocator with optional max capacity enforcement
- Str and StrSlice string types for safe and efficient
  string handling that does not rely on looking for a nul terminator
- Implementation of SipHash-2-4 algorithm for a fast, flood-resistant hash
- StrMap hash table with Str keys and opaque-typed values
